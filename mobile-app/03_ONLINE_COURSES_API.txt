1. GET /api/courses
--------------------------------------------------------------------------------
Purpose:
Search, filter, and paginate through verified online courses in the marketplace.

HTTP Method:
GET

Headers:
Accept: application/json

Query Parameters:
- search (string, optional): Keyword query (searches course title, description, instructor)
- category (string, optional): Category slug (e.g. "it-software", "digital-marketing")
- min_price (numeric, optional): Minimum sell price
- max_price (numeric, optional): Maximum sell price
- sort (string, optional): "price_asc", "price_desc", "newest", "popular", "rating"
- page (integer, optional): Page number (default: 1)
- per_page (integer, optional): Items per page (default: 15, max: 50)

cURL Example:
curl -X GET "https://web.digitalclassworld.in/api/courses?search=Python&sort=popular" \
     -H "Accept: application/json"

pricing breakdown, guarantees, and verified certificates.

URL Parameter:
- id: Numeric course ID OR slug string (e.g., "12" or "complete-python-masterclass")
