2. POST /api/coupons/validate
--------------------------------------------------------------------------------
Purpose:
Verify validity of a coupon code against the cart total, check expiry, 
and calculate the exact discount amount and net total.

HTTP Method:
POST

Headers:
Accept: application/json
Content-Type: application/json

Request Body Schema:
{
  "code": "WELCOME10",  // Required: Coupon code (case-insensitive)
  "total": 3049.00,     // Required: Current cart subtotal
  "context": "all"      // Optional: "courses", "products", "services", "all"
}

Sample Success Response (200 OK):
{
  "success": true,
  "code": "WELCOME10",
  "coupon_code": "WELCOME10",
  "discount_type": "percentage",
  "discount_percentage": 10,
  "discount_amount": 304.90,
  "subtotal": 3049.00,
  "final_total": 2744.10,
  "message": "Coupon WELCOME10 applied successfully! You saved ₹304.90"
}

Invalid Coupon Response (422 / 200 with success: false):
{
  "success": false,
  "message": "Invalid coupon code or expired."
}
