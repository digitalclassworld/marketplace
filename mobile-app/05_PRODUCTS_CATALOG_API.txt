MODULE 05: PRODUCTS CATALOG API (BOOKS, KITS & HARDWARE)
================================================================================

1. GET /api/products
--------------------------------------------------------------------------------
Purpose:
Search and filter physical study materials, educational books, electronics/robotics kits,
and digital learning resources.

HTTP Method:
GET

Headers:
Accept: application/json

Query Parameters:
- search (string, optional): Keyword query
- category (string, optional): Category slug
- brand (string, optional): Brand filter
- min_price (numeric, optional): Minimum price
- max_price (numeric, optional): Maximum price
- page (integer, optional): Page number

Sample Success Response (200 OK):
{
  "success": true,
  "data": {
    "total": 64,
    "items": [
      {
        "id": 1,
        "title": "Python Programming Complete Study Kit & Lab Manual",
        "slug": "python-study-kit",

        "rating": 4.8
      }
    ]
  }
}

2. GET /api/products/{id}
--------------------------------------------------------------------------------
Purpose:
Fetch comprehensive product specifications, stock status, shipping details,
and seller store credentials.

HTTP Method:

URL Parameter:
- id: Numeric product ID or slug
