================================================================================

1. GET /api/app/config
--------------------------------------------------------------------------------
Purpose:
Fetch client configuration, active feature toggles, maintenance mode flags, and minimum
supported version for force-update workflows on app launch.

HTTP Method:
GET

Query Parameters:
- platform (string, optional): "android" or "ios" (default: "android")

Headers:
Accept: application/json

cURL Example:
curl -X GET "https://web.digitalclassworld.in/api/app/config?platform=android" \
     -H "Accept: application/json"

2. GET /api/home/feed
--------------------------------------------------------------------------------
Purpose:
Aggregates all critical sections required to render the app's rich landing / home screen 
in a single round-trip.

HTTP Method:
GET

Headers:
Accept: application/json

Query Parameters:
- city (string, optional): Filter institutes/businesses by city (e.g., "Ahmedabad")

cURL Example:
curl -X GET "https://web.digitalclassworld.in/api/home/feed?city=Ahmedabad" \
