1. GET /api/categories
--------------------------------------------------------------------------------
Purpose:
Retrieve marketplace categories hierarchy used to build browse drawer, category pills,
and search filters for Courses, Services, Products, and Business Listings.

HTTP Method:
GET

Headers:
Accept: application/json

Query Parameters:
- type (string, optional): "all", "course", "service", "product", "business"

cURL Example:
curl -X GET "https://web.digitalclassworld.in/api/categories?type=course" \
     -H "Accept: application/json"
