--------------------------------------------------------------------------------
INDEX OF ALL 24 REST API ENDPOINTS
--------------------------------------------------------------------------------
1.  GET  /api/app/config                  -> App version, feature flags, maintenance
2.  GET  /api/home/feed                   -> Full landing screen feed
3.  POST /api/auth/register               -> Register customer account with profession
4.  POST /api/auth/login                  -> Customer login via email or phone
5.  GET  /api/auth/profile                -> Current customer profile and stats
6.  PUT  /api/auth/profile                -> Update customer profile details
7.  POST /api/auth/logout                 -> Invalidate bearer token
8.  GET  /api/courses                     -> Search, filter, paginate online courses
9.  GET  /api/courses/{id}                -> Course detail with curriculum & instructor
10. GET  /api/services                    -> Search & filter professional services
11. GET  /api/services/{id}               -> Service details, multi-tier packages
12. POST /api/services/{id}/book          -> Submit booking or quote inquiry
13. GET  /api/products                    -> Search physical & digital study products
14. GET  /api/products/{id}               -> Product details, specs, stock
15. GET  /api/businesses                  -> Business listings directory (Premium first)
16. GET  /api/businesses/{id}             -> Full institute profile & branches
17. POST /api/businesses/{id}/enquiry     -> Send direct student inquiry lead
18. POST /api/businesses/{id}/demo        -> Book free demo session
19. GET  /api/categories                  -> Hierarchical marketplace categories
20. GET  /api/cart                        -> View active shopping cart items
21. POST /api/cart/add                    -> Add course, product, or service to cart
22. POST /api/cart/update                 -> Update item quantity
23. POST /api/cart/remove                 -> Remove single item from cart
24. POST /api/cart/clear                  -> Clear shopping cart
25. POST /api/cart/checkout               -> Submit order (Razorpay, Bank Transfer, COD)
26. GET  /api/orders                      -> Customer purchase history & enrollments
27. GET  /api/coupons/available           -> List active promotional coupons
28. POST /api/coupons/validate            -> Check promo code & calculate discount
