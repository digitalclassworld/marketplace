1. GET /api/businesses
--------------------------------------------------------------------------------
Purpose:
Search and list verified coaching institutes, schools, tutoring centers, and educational
businesses.
NOTE: Institutes subscribed to Premium/Pro subscription plans are automatically 
ranked first with priority suggestion badges.

HTTP Method:
GET

Headers:
Accept: application/json

Query Parameters:
- search (string, optional): Keyword query (institute name, specialty, address)
- city (string, optional): Filter by city (e.g. "Ahmedabad", "Bangalore")
- category (string, optional): Category filter
- page (integer, optional): Page number

2. GET /api/businesses/{id}
--------------------------------------------------------------------------------
Purpose:
Fetch comprehensive institute profile: contact details, branch addresses, facilities,
faculty, photo gallery, and complete list of classroom & online courses offered.

HTTP Method:
GET

URL Parameter:
- id: Numeric business listing ID or slug (e.g., "1238" or "almamate-info-tech")

3. POST /api/businesses/{id}/enquiry
--------------------------------------------------------------------------------
Purpose:
Submit a student enquiry lead directly to the coaching institute.

HTTP Method:
POST

Request Body:
{
  "name": "Vaibhavi Shah",
  "email": "vaibhavi@gmail.com",
  "phone": "5874142536",
  "course_interested": "Salesforce Administrator",
  "message": "Please send batch timings and fee structure."
}

Sample Success Response (200 OK):
{
  "success": true,
  "message": "Enquiry submitted successfully! The institute counselor will call you within 24 hours.",
  "enquiry_id": 9182
}

--------------------------------------------------------------------------------
4. POST /api/businesses/{id}/demo
--------------------------------------------------------------------------------
Purpose:
Book a Free Demo Class at the institute.

HTTP Method:
POST

Request Body:
{
  "name": "Vaibhavi Shah",
  "email": "vaibhavi@gmail.com",
  "phone": "5874142536",
  "preferred_date": "2026-12-01",
  "preferred_time": "10:00 AM",
  "mode": "online" // or "classroom"
}

Sample Success Response (200 OK):
{
  "success": true,
  "message": "Free demo session confirmed! Pass and meeting link sent to your email & mobile.",
  "booking_code": "DEMO-8472"
}
