================================================================================
DIGITAL CLASS - COMPLETE AUTHENTICATION & REGISTRATION API SPECIFICATION
(CUSTOMER SIGNUP / LOGIN & SELLER SIGNUP / LOGIN)
================================================================================
Base URL: https://web.digitalclassworld.in
All Endpoints Format: JSON (REST API)
Standard Headers:
  Accept: application/json
  Content-Type: application/json
Protected Endpoints Header:
  Authorization: Bearer <AUTH_TOKEN>

================================================================================
PART 1: CUSTOMER (STUDENT / BUYER) AUTHENTICATION & SIGNUP
================================================================================

1.1 POST /api/auth/register
--------------------------------------------------------------------------------
Purpose:
Register a new customer / student account. Customers can immediately start 
browsing courses, services, and products, applying coupons, and placing orders.

HTTP Method:
POST

URL:
https://web.digitalclassworld.in/api/auth/register

Request Headers:
  Accept: application/json
  Content-Type: application/json

Request Body Parameters:
  - name                  (string, required, max: 100): Full customer name
  - email                 (string, required, email, max: 100, unique in users): Email address
  - phone                 (string, required, min: 10, max: 20): Mobile number
  - password              (string, required, min: 6): Account password
  - password_confirmation (string, optional): Must match password if provided
  - profession            (string, required): Student, Teacher, Professional, Job Seeker, etc.
  - city                  (string, optional, default: "Ahmedabad"): City name
  - state                 (string, optional, default: "Gujarat"): State name

cURL Example:
curl -X POST "https://web.digitalclassworld.in/api/auth/register" \
     -H "Accept: application/json" \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Vaibhavi Shah",
       "email": "vaibhavi.customer@gmail.com",
       "phone": "9876543210",
       "profession": "Student",
       "city": "Ahmedabad",
       "state": "Gujarat",
       "password": "Password@123"
     }'

Success Response (201 Created):
{
  "success": true,
  "message": "Account created successfully!",
  "token": "MjU6ZTFiM2Q1YjhhZGMwYTc3ZDYxNzJjYjM5MmM2MzE3ODQ0OTBhOGY3Nw==",
  "user": {
    "id": 25,
    "name": "Vaibhavi Shah",
    "email": "vaibhavi.customer@gmail.com",
    "phone": "9876543210",
    "profession": "Student",
    "avatar": "https://ui-avatars.com/api/?name=Vaibhavi+Shah&background=0066ff&color=fff&size=128&bold=true",
    "city": "Ahmedabad",
    "state": "Gujarat",
    "role": "customer"
  }
}

Validation Error Response (422 Unprocessable Entity):
{
  "success": false,
  "message": "The email has already been taken.",
  "errors": {
    "email": ["The email has already been taken."]
  }
}

1.2 POST /api/auth/login
--------------------------------------------------------------------------------
Purpose:
Sign in to an existing customer account via Email OR Mobile Phone.

HTTP Method:
POST

URL:
https://web.digitalclassworld.in/api/auth/login

Request Headers:
  Accept: application/json
  Content-Type: application/json

Request Body Parameters:

2.1 POST /api/seller/auth/register
--------------------------------------------------------------------------------
Purpose:
Register a new seller account (Instructor, Coaching Institute, or Business Store)
to publish courses, offer professional services, and sell products.

HTTP Method:
POST

URL:
https://web.digitalclassworld.in/api/seller/auth/register

Request Headers:
  Accept: application/json
  Content-Type: application/json

Request Body Parameters:
  - name                  (string, required, max: 100): Full contact person name
  - email                 (string, required, email, max: 100, unique in users): Official email
  - phone                 (string, required, max: 20): Official phone / WhatsApp
  - password              (string, required, min: 6): Account password
  - account_type          (string, optional): "Institute / Company" | "Individual / Freelancer" | "Agency"
                          (Defaults to "Individual / Freelancer")
  - business_name         (string, optional, max: 150): Institute or Store display name
  - business_category     (string, optional, max: 100): Primary category (e.g., "IT & Software Training")
  - business_email        (string, optional, email): Public store email
  - business_phone        (string, optional): Public store phone
  - business_description  (string, optional): About the institute / academy
  - website               (string, optional): Official website link
  - address               (string, optional): Physical address
  - city                  (string, optional, default: "Ahmedabad"): City
  - state                 (string, optional, default: "Gujarat"): State
  - pincode               (string, optional): Area pincode

cURL Example:
curl -X POST "https://web.digitalclassworld.in/api/seller/auth/register" \
     -H "Accept: application/json" \
     -H "Content-Type: application/json" \
     -d '{
       "name": "Apex Skill Institute",

================================================================================
PART 3: COMMON SECURITY & INTEGRATION NOTES
================================================================================

1. Authentication Token Format:
   The token is returned in the "token" attribute of the response. Mobile apps
   must save this token locally (e.g. SharedPreferences on Android, Keychain on iOS)
   and supply it in the header for all protected endpoints:
   Authorization: Bearer <token>

2. Multi-Role Capability:
   If a user registers as a customer and later registers or logs into the seller portal,
   their role automatically updates to "seller" and their seller profile is activated.

3. Cross-Platform Login Identifiers:
   Both login endpoints accept:
   - Case-insensitive Email
   - Mobile Phone Number (with or without +91)
   - Seller ID (e.g. DC-SELL-000028) on seller endpoints.
