MODULE 04: PROFESSIONAL SERVICES & DIRECT BOOKING API
================================================================================

1. GET /api/services
--------------------------------------------------------------------------------
Purpose:
Search and filter professional gigs & freelance services (Web Development, SEO, 
Graphic Design, App Development, Content Writing, Digital Marketing).

HTTP Method:
GET

Headers:
Accept: application/json

Query Parameters:
- search (string, optional): Keyword query
- category (string, optional): Service category filter
- min_price (numeric, optional): Minimum budget
- max_price (numeric, optional): Maximum budget
- page (integer, optional): Page number

3. POST /api/services/{id}/book
--------------------------------------------------------------------------------
Purpose:
Submit a direct booking request or quote enquiry for a service.

HTTP Method:
POST

Headers:
Accept: application/json
Content-Type: application/json

Request Body:
{
  "package": "standard",                   // Required: basic, standard, or premium
  "name": "Vaibhavi Shah",                 // Required
  "email": "vaibhavi@gmail.com",           // Required
  "phone": "5874142536",                   // Required
  "project_brief": "We need an LMS app..." // Required
}

Sample Success Response (200 OK):
{
  "success": true,
  "message": "Service booking request submitted! The service provider will contact you shortly.",
  "booking_reference": "#SB-84920"
}
