1. GET /api/cart
--------------------------------------------------------------------------------
Purpose:
Retrieve all items currently stored in the customer's cart, subtotal, and total quantity.

HTTP Method:
GET

Headers:
Accept: application/json
Authorization: Bearer <TOKEN> (Optional for guests, supported via session / device)

2. POST /api/cart/add
--------------------------------------------------------------------------------
Purpose:
Add a Course, Product, or Service item into the shopping cart.

HTTP Method:
POST

Request Body Schema:
{
  "id": "12",                     // Required: Item ID
  "type": "Course",               // Required: Course, Product, or Service
  "title": "3D Epoxy Design...",  // Required: Item title (also accepts "name")
  "price": 2250.00,               // Required: Numeric price
  "original_price": 4500.00,      // Optional: Original MRP price
  "thumbnail": "https://...",     // Optional: Image URL (also accepts "image")
  "quantity": 1,                  // Optional: Default is 1
  "coupon_code": "WELCOME10",     // Optional: Discount coupon
  "discount_amount": 225.00       // Optional: Pre-calculated discount
}

Sample Success Response (200 OK):
{
  "success": true,
  "message": "Item added to cart successfully!",
  "count": 2,
  "total": 3049.00
}

--------------------------------------------------------------------------------
3. POST /api/cart/update
--------------------------------------------------------------------------------
Purpose:
Update quantity of an item inside the cart. Setting quantity to 0 removes the item.

Request Body:
{
  "key": "course_12",
  "quantity": 2
}

Sample Success Response (200 OK):
{
  "success": true,
  "count": 3,
  "total": 5299.00
}

--------------------------------------------------------------------------------
4. POST /api/cart/remove
--------------------------------------------------------------------------------
Purpose:
Remove a single item from the cart.

Request Body:
{
  "key": "course_12"
}

Sample Success Response (200 OK):
{
  "success": true,
  "message": "Item removed from cart",
  "count": 1,
  "total": 799.00
}

--------------------------------------------------------------------------------
5. POST /api/cart/clear
--------------------------------------------------------------------------------
Purpose:
Empty the entire shopping cart.

Sample Success Response (200 OK):
{
  "success": true,
  "message": "Cart cleared",
  "count": 0,
  "total": 0.00
}

--------------------------------------------------------------------------------
6. POST /api/cart/checkout
--------------------------------------------------------------------------------
Purpose:
Place the order, create order records in the database, calculate discounts, 
and generate confirmed enrollment credentials.

HTTP Method:
POST

Headers:
Accept: application/json
Content-Type: application/json
Authorization: Bearer <TOKEN> (Optional: Guest checkout supported with automatic account creation)
